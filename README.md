# V Tech Systems and Services — Website

A responsive, single-page website for **V TECH SYSTEMS AND SERVICES**. Built with plain HTML, CSS and JavaScript. No framework, build step, database, paid theme or external dependency is required.

## Preview locally

1. Extract the ZIP file.
2. Open `index.html` in a modern browser (Chrome, Edge, Firefox or Safari).
3. Keep the `assets` folder beside `index.html`; the page loads its images from that folder.

## Publish with GitHub Pages (free)

1. Sign in to [GitHub](https://github.com/).
2. Create a new repository, for example `vtechsystems-website`.
3. Upload **all contents of this folder** (the `index.html`, `README.md`, `.nojekyll`, and `assets` folder) to the repository root. Do not upload only `index.html`.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for GitHub Pages to finish publishing. Your website address will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/vtechsystems-website/`
